## Rules a future session must not get wrong
- **★ NEVER GATE ON CLIP SHARE — use IN-MASK CHROMA.** Every compressive operator drives clip share to 0.000 while the surface stays white and flat. Nothing in `src/` gates on clip share.
- **★ UF shape names do not transfer by name**; per-shape thresholds are coverage-anchored.
- **★ ANY NEW FIELD-SIDE RENDER AXIS MUST ENTER THE FIELD-CACHE/REPLAY IDENTITY KEY** [`test_renders.py`; digests pinned in `test_curation_colorize.py`]. A variant through `mode_params` needs no new axis. **Serialization is a RECORD KEY**: new fields `skip_serializing_if` their default or every cached picture renames; colormap-TAIL operators identify via provenance stamps.
- **★ ⚠ `renders.job_name` IS NOT A DURABLE IDENTITY** — a truncated sha256 of the whole spec INCLUDING `colormap_dir`, an absolute path into the CHECKOUT (not the artifact root): a re-clone misses the render cache, a hot-root move does not. **Never pin its digest in a test** (unenforced; it left CI red for three days once). A test that patches `renders.colormap_dir` to hold a field-name digest is the same trap — after `engine_spec` moved the key it would have digested the checkout silently (found and fixed ckpt 105). It does NOT carry the mode catalog — adding a catalog entry renames nothing.
- **★ `autolevel` IS A PIXEL-DECIDING INPUT OUTSIDE EVERY OTHER DIGEST** [`autolevel.applies_to`; the band sha in `recipes.KEYED`; `test_candidate_ledger.py`]. Supersampling and JPEG average colour AFTER the lookup; exact only at ss1/PNG. **A ledger row cannot replay its levelled colormap** (`recipes.stamp_of` drops the curve; `<key>.leveled/` is RE-RENDERABLE, a `manufacture` row replayable). **The operator's input is the ENCODED picture and the engine route is CLOSED (measured)** — the same field to `.jpg` and `.png` changes the levelled stop list. ⚠ **A `depth` run record kept only `acted` before ckpt 103** — since then `sequence.jsonl` carries the whole stamp, one spelling with the reframe and gallery writers, and `depth.levelling_of` is the three-way reader (a pre-stamp acted row never reads as untouched) [`tests/test_depth_stamp_replay.py`]; 52.8% of depth rows over 51 runs and 33.4% of a gallery's SEATS (305 of 914; 243 of 1,000 — a STEM join; a key join loses `runs`/`reframe_draw` rows) stay UNREPLAYABLE (`acted_unrecoverable`; the website ships the stored file, never a mis-draw) — re-measuring derives a DIFFERENT curve, so it is not a way out. A 17-of-241 "stale seat" finding (ckpt 107) was a reader taking `gallery.mode` (the ROUTED mode) instead of `recipe["mode"]`: at the recipe's mode all 17 are sha256-identical to the shipped file — the first pixel-level proof of the texture_flat bit-for-bit claim. The `mine` leg has the same gap (parked → fractal-state).
- **★ THE FIELD IS DUMPABLE AND A RECOLOUR IS BYTE-IDENTICAL TO A RENDER** [`test_curation_colorize.py`, slow; the composite/direct-trap refusal in `mode.rs`]. **The dump amortises per (location, MODE) — cutting the mode roster is a bigger lever than cutting palettes.** ⚠ A field dumped BY MODE NAME carries the CATALOGUE's curve (silent wrongness, not an error). Composites and direct traps cannot dump.
- **★ THE ENGINE BUILD IS THE FIFTH PIN** (beside colormap, cyclicity, node width, cap policy): `identity.enforce` + `drawn_by.jsonl`; an unstamped or mismatched view is STALE = re-rendered, never scored [`test_engine_fingerprint.py`; the gate in `curation/intake.py`]. The stamp is BESIDE the picture. Scores overlay `score_amendments.jsonl` via `intake.read_scores` — **never open the sidecar directly** (unenforced). ⚠ **PRE-ckpt-103 CANDIDATE ROWS (182,132) CARRY NO ENGINE STAMP** — the pin guards VIEWS only; pre-stamp material is ACCEPTED as unknown-engine (Matt). **Since ckpt 103 every row is stamped at `candidate_ledger.row` as PROVENANCE, never a gate** (30 bytes; absent reads unknown-engine, one spelling; a backfill keeps an existing stamp; the recipe key is unchanged) [`code: curation/candidate_ledger/` — a package since ckpt 105, `row` in `rows.py`]; a mismatch on a candidate never voids the pool; re-render policy per engine change is Matt's. The fingerprint is SPLIT [`engine_fingerprint`]: `IDENTITY_PROBES` (the six, the only digest that stamps) · `TRAP_PROBES` (one per direct trap) · `coverage()` digests both and stamps nothing — a NEW mode is invisible to the identity digest (`mode_policy.check` is what a new mode trips), and **the only guard on a direct-trap pixel change is `test_a_regenerated_picture_is_the_picture_that_was_judged`** (24 rows a head).
- **★ THE HOME VIEW IS A RUST CONSTANT** — `Family::home_view()` → `Extent::frame()`, 9/16; Python holds NO copy, the one door is `engine.home_view(family)` [`test_home_views.py`; the website's `permalink.test.mjs` pins all nine families as text]. The julia exception is CRATE-INTERNAL. `CLASSIC_PHOENIX_POINT` is the shared spelling of the pinned phoenix plane (`pools.classic_phoenix_pool()`).
- **★ TWO SHIPPED MODULATES** [`mode.rs` asserts two]; `itinerary` is production (weight 2), `tail_itinerary` weight 0 by ruling. Where the base is FLAT the shift is the only variation — the texture fills the BORING regions. Catalogue 8 field + 6 composite + 2 modulate + 4 direct = 20, `de` niche, 19 production [the split test in `mode.rs`]; `MODE_POLICY` weights 13 of the 19 above zero (ckpt 106: `exp_smoothing` niche — same picture as `smooth` at 98.7% of seats; → fractal-tutorial).
- **★ A FLAT TEXTURE IS SMOOTH-WITH-RANK (ruling, ckpt 94)** — `texture_flat` per render, bit-for-bit against `smooth` + rank transfer [the engine guard; `tests/test_texture_flat.py`]; the ONE routing spelling is `mode_policy.routed_mode` / `hunt.kind_of`. **`data/coloring/texture_flat.jsonl` is a TRACKED register keyed on the engine spec less the recolour half — GEOMETRY IS IN THE KEY** (per location, mode, geometry). It SELF-EXTENDS on a miss at `finished.append` (span test at the row's geometry; refuses on a failed probe; readers never render) [`code: labeling/finished.py`]; store membership stays the kind for every reader (→ fractal-corpus). ⚠ The f32 field dump is NOT ground truth for the texture; truth is the engine's span test.
- **★ `direct_trap_multiply` WHITEWASHES BECAUSE `Blend::Multiply` FROM WHITE IS READ THROUGH sRGB** — perceptually it can barely leave white (mechanism, spread, fix prices → `engine/README.md §The direct traps`). NOT autolevel (never applies to `direct`), NOT the map, NOT mirroring (folding REDUCES it). **The fix is a MODE-PARAM VARIANT, never an engine edit** — `opacity`/`threshold` settings are a new recipe key, nothing re-keys, no label is voided; matched on place and map, `opacity 0.6 + threshold 0.2` takes near-white 0.36→0.00 and chroma 2.1× while the render judge's P(≥4) goes 0.81→0.01 on the same picture. The shipped white rows stay beside the tinted ones. **Adjudicated ckpt 103 (→ fractal-corpus): Matt's eye is chroma-indifferent, only the judge penalised the tint. Roster (ruled ckpt 104: a settings cell leaves only at zero clears) = bare · `@opacity=0.4` · `@opacity=0.6` · `@threshold=0.2` · `@opacity=0.6,threshold=0.2` — the both-knobs cell clears 7.8%, best of the five. Defaults `threshold=0.1, opacity=0.2` (`mode.rs`).**
- **★ `release.Task` CARRIES `mode_params` (fixed 2026-09-04)** — before, every release-size render of a varied seat was the BARE mode's picture, silently; the four builders are fixed and guarded. ⚠ **`release.parity` (`release.py:578`) still rebuilds its arms without `mode_params`** — a parity run over a varied plan compares two bare renders and passes (owed → state OPEN 4). The website never rendered through it (its own spec builder raises on an unknown setting; 0 of 89 cited seats varied). `SUPERSAMPLES = (1, 2, 4)`: ss1 is a DEBUG cell (4.9 s a 2560×1440 picture), ss2 18.4 s, ss4 76 s on depth-representative seats (31% of seats below 1e-6 width). **Bytes FALL with ss at equal q** (ss1 +20%, ss2 +8–12% over ss4 — supersampling removes what the codec pays for), so the final render's ss4 is the smaller file too; q80→q95 moves bytes 2.6× and |Δ| less than ss2→ss4 does. **Time a render pilot in SEAT ORDER, never by a byte-size spread** (it samples shallow places; 1.4× under-read).
- Diagnostic heuristics: **production mirrors non-cyclic colormaps** — a field piling up at one end loses nearly everything under a mirrored map; treat mirroring as a suspect when a trap-like mode underperforms — measured BACKWARDS for `direct_trap_multiply`, so check before assuming. **GENERICITY, NOT MULTIPLICITY, IS THE PERF TRAP** and FAMILY spread dwarfs mode spread — live numbers in website `explorer/README.md §Measured`. **`data/palettes` never stores the baked table size** — compare maps by SAMPLING through the bake's Oklab interpolation, unfolded (`palettes/README.md`).
