## Rules that transfer to any render work
- **★★ NEVER GATE ON CLIP SHARE — use IN-MASK CHROMA.** Every compressive operator drives clip share to 0.000 while the surface can stay white and flat.
- **★ UF shape names do not transfer by name** — same-named variants compute different functions; per-shape thresholds are coverage-anchored.
- **★ Any new FIELD-side render axis must enter the field-cache/replay identity key** — GUARDED [code: renders.SPEC_MEMBERS · FIELD_IDENTITY · RECOLOR_MEMBERS; `field_job_name` refuses an unclassified member; shipped digests pinned in tests]. `renders.job_name` = truncated sha256 of the WHOLE spec — ⚠ **AND IT DIGESTS `colormap_dir`, AN ABSOLUTE PATH INTO THE CHECKOUT, so it is MACHINE-DEPENDENT and is never a durable identity (ckpt 84; demonstrated — repoint the dir and the job name moves)**; harmless as a render-cache file name, a trap for anything else. **serialization is a RECORD KEY**: new fields `skip_serializing_if` their default or every cached picture renames; colormap-TAIL operators identify via provenance stamps.
- Multibrot z^d+c has (d−1)-fold rotational symmetry; phoenix symmetry is conjugation for all-real constants, reduces to quadratic julia at p=0.
- **fractional_multibrot:** principal branch, cut on the negative real axis; the real axis is NOT a seam on the parameter plane; below degree 2 the cut is PROMINENT and the subject, not an artifact; escape is FASTER below degree 2; bailout adequacy test-pinned [code: the_bailout_covers_the_lowest_degree].
- **★ MIRROR FOLDS PILE-UP FIELDS** — production mirrors non-cyclic colormaps; a field piling up at one end loses nearly everything under a mirrored map; figure/rank work uses plain sweeps; treat mirroring as the prime suspect when a trap-like mode underperforms.
- **★★ GENERICITY, NOT MULTIPLICITY, IS THE PERF TRAP.** `iterate::run` specializes only when family AND channel set are compile-time constant at an INLINED call site; production `field::sample` is SPECIALIZED [guards: in-tree bit-identity + coverage tests]; the FAMILY spread dwarfs the mode spread. **Never re-quote any perf figure from before ckpt 73**; the live numbers and the regression guard are website `explorer/README.md §Measured` + `explorer/bench/`. `field::sweep_row` / `field::Channels` are PUBLIC under the wasm-consumer carve-out (ckpt 78; one table for both sides; `smooth` pays a per-sample interior count the page discards — an unbuilt engine change). Identity chain GREEN across all 18 modes (ckpt 78).
- **★★ `autolevel` IS A PIXEL-DECIDING INPUT OUTSIDE EVERY DIGEST THIS PROJECT HAS (ckpt 83)** — the operator re-renders through a colormap built from the band file, so the picture is a function of `levels_band.json`'s sha too, and a picture is not a lookup into the map that named it (a reading moved teal 0.002 → 0.266 under levelling). Any recipe key must carry that sha. ⚠ **Supersampling and JPEG average colour AFTER the colormap lookup**, so a stored picture can hold colours no ramp position holds — exact only at ss1/PNG.
- **⚠ NO CANDIDATE RENDER CARRIES AN ENGINE STAMP (ckpt 83)** — `engine_fingerprint` stamps VIEW DIRECTORIES (`node_views/384x216ss1/`, gallery4's framings) and nothing else. Pre-stamp candidate material is ACCEPTED as unknown-engine (Matt, ckpt 83): the fifth pin catches future drift, it does not certify history.
- **★ THE ENGINE BUILD IS THE FIFTH PIN (ckpt 80)** — beside colormap, cyclicity, node width and cap policy: an engine-output fingerprint (six pinned probes, ~0.35 s) recorded by `identity.enforce`; `drawn_by.jsonl` stamps every node view AND gate render; **an unstamped or mismatched view is STALE = re-rendered, never scored** [code: engine_fingerprint.py · intake.gate_render · tests/test_engine_fingerprint.py]. The stamp is BESIDE the picture, not in its name (a build in the digest would orphan every `score_view`). Scores overlay `artifacts/curation/score_amendments.jsonl` via `intake.read_scores` — never open the sidecar directly; the amendment is regenerable (~2h23m), no durable copy. Caveats: `renders.job_name` carries the engine's mode catalog — a catalog field renames every cached view without changing a pixel and the fingerprint sees that only after the fact (catalog pin DECLINED, settled); `neutral_embeddings` carries no engine pin.
- **★ THE HOME VIEW IS A RUST CONSTANT** — `Family::home_view()` → `Extent::frame()` in `engine/src/family.rs`; height is always width × 9/16; Python holds NO copy — the one door is `engine.home_view(family)` (`discovery.boundary.home_box` shrinks it by `HOME_SHARE`; the website's `permalink.test.mjs` keeps a text copy; `engine.screen` is the gate battery, not a window) (ckpt 81).
- **wasm:** the lib compiles to wasm32 unmodified (rayon single-thread fallback) and whole-frame output is BYTE-IDENTICAL to native end-to-end (page download ≡ `fractal-engine render`; banded ≡ one-band). The bindings take ONE render spec with `family: FamilySpec` — a julia at a given `c` is the same calls, no family-specific entry point (exports and caps → website `explorer/README.md`). Crate `0.1.0` never bumped — consumers pin by path/rev; the weights tag is the render judge's (→ fractal-tutorial §THE REPO). `resample::downsample` at ss=1 is a single pass (byte-identical; the first attempt lost parallelism — watch that shape).
- **★ `data/palettes` stores 33 / 34 / 257 / 512 stops, NEVER 4096** — 4096 is the engine's baked table (`colormap.rs` `TABLE_SIZE`). Anything comparing maps must SAMPLE positions through the bake's Oklab interpolation, unfolded (check method → `palettes/README.md`; the Python-side gradient sits a fifth of an 8-bit step from the Rust bake). Gallery release regime → fractal-tutorial.
