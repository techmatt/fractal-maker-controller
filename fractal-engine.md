## Rules a future session must not get wrong
- **★ NEVER GATE ON CLIP SHARE — use IN-MASK CHROMA.** Every compressive operator drives clip share to 0.000 while the surface stays white and flat. Nothing in `src/` gates on clip share.
- **★ UF shape names do not transfer by name**; per-shape thresholds are coverage-anchored.
- **★ ANY NEW FIELD-SIDE RENDER AXIS MUST ENTER THE FIELD-CACHE/REPLAY IDENTITY KEY** [`test_renders.py`; digests pinned in `test_curation_colorize.py`]. A variant through `mode_params` needs no new axis. **Serialization is a RECORD KEY**: new fields `skip_serializing_if` their default or every cached picture renames; colormap-TAIL operators identify via provenance stamps.
- **★ ⚠ `renders.job_name` IS NOT A DURABLE IDENTITY** — a truncated sha256 of the whole spec INCLUDING `colormap_dir`, an absolute path into the CHECKOUT (not the artifact root): a re-clone misses the render cache, a hot-root move does not. **Never pin its digest in a test** (unenforced; it left CI red for three days once). It does NOT carry the mode catalog — adding a catalog entry renames nothing.
- **★ `autolevel` IS A PIXEL-DECIDING INPUT OUTSIDE EVERY OTHER DIGEST** [`autolevel.applies_to`; the band sha in `recipes.KEYED`; `test_candidate_ledger.py`]. Supersampling and JPEG average colour AFTER the lookup; exact only at ss1/PNG. **A ledger row cannot replay its levelled colormap** (`recipes.stamp_of` drops the curve; `<key>.leveled/` is RE-RENDERABLE, a `manufacture` row replayable). **The operator's input is the ENCODED picture and the engine route is CLOSED (measured)** — the same field to `.jpg` and `.png` changes the levelled stop list. ⚠ **A `depth` run record kept only `acted` until ckpt 102** (`sequence.jsonl`; reframe and gallery writers keep the whole stamp) — every earlier acted-on depth seat is UNREPLAYABLE (`acted_unrecoverable`; the website copies the seat's picture); re-measuring derives a DIFFERENT curve, so it is not a way out.
- **★ THE FIELD IS DUMPABLE AND A RECOLOUR IS BYTE-IDENTICAL TO A RENDER** [`test_curation_colorize.py`, slow; the composite/direct-trap refusal in `mode.rs`]. **The dump amortises per (location, MODE) — cutting the mode roster is a bigger lever than cutting palettes.** ⚠ A field dumped BY MODE NAME carries the CATALOGUE's curve (silent wrongness, not an error). Composites and direct traps cannot dump.
- **★ THE ENGINE BUILD IS THE FIFTH PIN** (beside colormap, cyclicity, node width, cap policy): `identity.enforce` + `drawn_by.jsonl`; an unstamped or mismatched view is STALE = re-rendered, never scored [`test_engine_fingerprint.py`; the gate in `curation/intake.py`]. The stamp is BESIDE the picture. Scores overlay `score_amendments.jsonl` via `intake.read_scores` — **never open the sidecar directly** (unenforced). ⚠ **CANDIDATE LEDGER ROWS CARRY NO ENGINE STAMP** (200k sampled) — the pin guards VIEWS only; pre-stamp material is ACCEPTED as unknown-engine (Matt). **Ruled ckpt 102: stamp candidate rows at intake as PROVENANCE, never a gate** — a mismatch on a candidate never voids the pool; re-render policy per engine change is Matt's (owed). The fingerprint is SPLIT [`engine_fingerprint`]: `IDENTITY_PROBES` (the six, the only digest that stamps) · `TRAP_PROBES` (one per direct trap) · `coverage()` digests both and stamps nothing — a NEW mode is invisible to the identity digest (`mode_policy.check` is what a new mode trips), and **the only guard on a direct-trap pixel change is `test_a_regenerated_picture_is_the_picture_that_was_judged`** (24 rows a head).
- **★ THE HOME VIEW IS A RUST CONSTANT** — `Family::home_view()` → `Extent::frame()`, 9/16; Python holds NO copy, the one door is `engine.home_view(family)` [`test_home_views.py`; the website's `permalink.test.mjs` pins all nine families as text]. The julia exception is CRATE-INTERNAL. `CLASSIC_PHOENIX_POINT` is the shared spelling of the pinned phoenix plane (`pools.classic_phoenix_pool()`).
- **★ TWO SHIPPED MODULATES** [`mode.rs` asserts two]; `itinerary` is production (weight 2), `tail_itinerary` weight 0 by ruling. Where the base is FLAT the shift is the only variation — the texture fills the BORING regions. Catalogue 8 field + 6 composite + 2 modulate + 4 direct = 20, `de` niche, 19 production [the split test in `mode.rs`].
- **★ A FLAT TEXTURE IS SMOOTH-WITH-RANK (ruling, ckpt 94)** — `texture_flat` per render, bit-for-bit against `smooth` + rank transfer [the engine guard; `tests/test_texture_flat.py`]; the ONE routing spelling is `mode_policy.routed_mode` / `hunt.kind_of`. **`data/coloring/texture_flat.jsonl` is a TRACKED register keyed on the engine spec less the recolour half — GEOMETRY IS IN THE KEY** (per location, mode, geometry). ⚠ The f32 field dump is NOT ground truth for the texture; truth is the engine's span test.
- **★ `direct_trap_multiply` WHITEWASHES BECAUSE `Blend::Multiply` FROM WHITE IS READ THROUGH sRGB** — perceptually it can barely leave white (mechanism, spread, fix prices → `engine/README.md §The direct traps`). NOT autolevel (never applies to `direct`), NOT the map, NOT mirroring (folding REDUCES it). **The fix is a MODE-PARAM VARIANT, never an engine edit** — `opacity`/`threshold` settings are a new recipe key, nothing re-keys, no label is voided; matched on place and map, `opacity 0.6 + threshold 0.2` takes near-white 0.36→0.00 and chroma 2.1× while the render judge's P(≥4) goes 0.81→0.01 on the same picture. The shipped white rows stay beside the tinted ones; Matt's eye adjudicates (→ fractal-corpus).
- Diagnostic heuristics: **production mirrors non-cyclic colormaps** — a field piling up at one end loses nearly everything under a mirrored map; treat mirroring as a suspect when a trap-like mode underperforms — measured BACKWARDS for `direct_trap_multiply`, so check before assuming. **GENERICITY, NOT MULTIPLICITY, IS THE PERF TRAP** and FAMILY spread dwarfs mode spread — live numbers in website `explorer/README.md §Measured`. **`data/palettes` never stores the baked table size** — compare maps by SAMPLING through the bake's Oklab interpolation, unfolded (`palettes/README.md`).
