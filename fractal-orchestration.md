# fractal-orchestration — production loop & run safety

Changes when: orchestrator work. Owns how runs launch, isolate, and stop.

**Production loop:** `tools/atlas/steered_frontier.py` (batch loop, active-time budget, per-batch state, sentinel at batch boundary); production flags `--scheduler` + `--freshness-prior` (breadth ONLY) → run-scoped ledger → dive leg (`--dive`, scheduler-ordered, prior OFF) → stage-1 intake (`tools/emission/`) → colorize/gate/pool/select → RELEASE. GPU-EXCLUSIVE phasing (one 8 GB card). `production_seeder.py` (26 importers) is the standing discovery flow; `present` has no live invoker.

- **Durable principles:** cap = accumulated active time; sentinel-stop at the state-consistent boundary; reconciliation per unit (`found == written + dropped_*` else loud exit); TWO dedup layers (any rate on raw decodes ~2× optimistic); operational failure ≠ leak. **Launch long runs DETACHED** — the reaper kills waited/shelled tasks, never detached processes. An ACTIVE cap alone does not bound wall (`draw_roots` sits outside it) — pair with `--wall-budget`; a STOP sentinel at a batch boundary is the clean external cut.
- **Per-check telemetry is DURABLE** — `harvest_log.jsonl` committed beside the ledger, so every run regenerates the τ_h cost curve automatically. ⚠ `campaign1`'s 37,853 rows are pre-geometry, not re-scoreable, permanently.
- **★ A scheduler run refuses to start unseeded** — `require_library_seed()` raises (`--allow-unseeded`, scoped to `--scheduler`), preflight before any write; `summary.json` carries `library_seed` + a screaming `UNSEEDED_RUN` key; a never-called seeder records `never_attempted`, not an absent key.
  - **⚠ THE SEED IS CURRENTLY UNAVAILABLE IN PRINCIPLE** — `campaign1_intake` selects on current-decode and every campaign ledger row went non-current at the v8 flip, so a rebuild embeds zero rows. Self-heals through the next discovery run's admissions; **run scheduler-off meanwhile.**
- **★ SINK ISOLATION (`tools/atlas/discovery_sinks.py`) — one decision point.** `--smoke`/`--time-only` with no explicit `--discovery-dir` redirects the WHOLE discovery store to ephemeral scratch. Smoke rows are current-decode ⇒ admissible — contamination the decode firewall cannot catch. **A real experimental run is NOT a smoke — give it its own run directory.** `steered_frontier` has no smoke flag and takes an explicit `--run-dir` with no default, so it cannot fall through to the production store.
- **★ CONCURRENCY — 7 IS THE NUMBER.** (a) ONE `fractal-generator.exe` → 7 threads; (b) 4+ in parallel → think, no standing number. **BelowNormal ALWAYS.** Committed defaults: `corpus_common.DEFAULT_ENGINE_THREADS` + `default_engine_env()` / `default_creationflags()` — **call the helpers, never restate the number.** `render_core.run_render_one` defaults `low_priority=True` (explorer = the one opt-out). Machine: 12 logical cores, RTX 2060 SUPER 8 GB.
- **The suite can't see the loud-late surface** → before trusting a structural change: both legacy orchestrators `--mini` + `production_seeder --smoke` + a frontier smoke; sink isolation means none can reach production data. `deploy_tail` sites are NOT on that surface (fractal-emission).
- **Reject autopsy — standing habit:** fate-stratified sheets at deploy fidelity; every readout emits numbers AND a visual sample of admissions + rejects.
- **LEGACY (reference; byte-preserved for A/B):** `prospect_orchestrator.py` · `overnight_orchestrator.py` (owns the GPU-phase/wall-cap machinery prospect imports — don't delete).
