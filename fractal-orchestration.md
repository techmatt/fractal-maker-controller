# fractal-orchestration — production loop & run safety

Changes when: orchestrator work. Owns how runs launch, isolate, and stop. **Run-safety mechanics (detach, liveness, atomic writes, resume, shakedown, caps) → `docs/design/verification_practice.md` §11 — cite in prompts, never restate.**

**Production loop:** `tools/atlas/steered_frontier.py` (batch loop, active-time budget, per-batch state, sentinel at batch boundary); **allocator = `--pop-quota`** (`--scheduler` retired; mutually exclusive; targets ∝ `release_mix` — fractal-discovery owns the rule) + `--freshness-prior` (breadth ONLY) → run-scoped ledger → dive leg (`--dive`, prior OFF) → stage-1 intake → colorize/gate/pool/select → RELEASE. GPU-EXCLUSIVE phasing (one 8 GB card). `production_seeder.py` is the standing discovery flow.

- **Durable principles:** cap = accumulated active time; sentinel-stop at the state-consistent boundary; reconciliation per unit (`found == written + dropped_*` else loud exit); TWO dedup layers (any rate on raw decodes ~2× optimistic); operational failure ≠ leak. An ACTIVE cap alone does not bound wall — pair with `--wall-budget` (clock starts at LOOP ENTRY; never covers the pre-loop draw; refused in dive mode [code: `check_wall_budget_supported`]). Per-check telemetry durable (`harvest_log.jsonl` beside the ledger — the τ_h cost curve regenerates).
- **The pre-loop root draw runs OUTSIDE both caps — bounded via `--root-draw-budget`** [code]; deadline arithmetic subtracts the draw bound explicitly. Cost is set by CONTENTION, not family count. **Size at `wall_over_active` 1.15** — realized 1.01–1.02 on bounded production runs; **★ apply the margin PER-LEG, not to the whole-run cap** [run 25: 8h/1.15 for the frontier alone leaves no room for the other legs — the multi-leg pattern].
- **Per-partition refill** [code: `steered_frontier.refill_starved`]: low-water fires `draw_roots` for starved partitions; cooldown + `--root-refill-share` (the ONLY bound on refill spend). **The pre-loop draw dominates any short frontier smoke** — budget wall for it; `production_seeder --smoke` has BUFFERED stdout — read `<sink>/outcome_ledger.jsonl` for progress.
- **★ A scheduler run refuses to start unseeded** — `require_library_seed()` raises; `summary.json` carries `library_seed` + a screaming `UNSEEDED_RUN` key. Seed at registered BULK (ordered REGISTRY; resolvers REFUSE scratch paths [code]); pop-quota never reads it.
- **★ SINK ISOLATION (`tools/atlas/discovery_sinks.py`) — one decision point.** `--smoke`/`--time-only` with no explicit `--discovery-dir` redirects the WHOLE discovery store to ephemeral scratch. Smoke rows are current-decode ⇒ admissible — contamination the decode firewall cannot catch. **A real experimental run is NOT a smoke — give it its own run directory.** `steered_frontier` takes an explicit `--run-dir` with no default, so it cannot fall through to the production store.
- **★ CONCURRENCY — 7 IS THE NUMBER.** (a) ONE `fractal-generator.exe` → 7 threads; (b) 4+ in parallel → think. **BelowNormal ALWAYS.** Committed defaults: `corpus_common.DEFAULT_ENGINE_THREADS` + `default_engine_env()` / `default_creationflags()` — **call the helpers, never restate the number.** `run_render_one` defaults `low_priority=True` (explorer = the one opt-out). Machine: 12 logical cores, RTX 2060 SUPER 8 GB.
- **The suite can't see the loud-late surface** → before trusting a structural change: both legacy-path minis + `production_seeder --smoke` + a frontier smoke + the sink-isolated emission smoke; sink isolation means none can reach production data. **Reject autopsy — standing habit:** fate-stratified sheets at deploy fidelity; every readout emits numbers AND a visual sample of admissions + rejects.
- **Dive legs:** plan arms apportionment-interleaved so truncation keeps both arms [code: `interleave_dive_arms`]; the dive path writes `run_config.json`. **Run-record telemetry is SEGMENTED** [code: `tools/run_record.py`]: heavy jsonl streams rotate into gzipped segments + bounded plain tail; readers via `run_record.iter_rows`; assert the registry's LOGICAL stream (`run_record.exists()`), never the physical filename.
- **★ `steered_frontier` TEARS DOWN ITS OWN SCRATCH ON CLEAN CLOSE** [code; `--retain-scratch` opts out; an INTERRUPTED run never tears down] — generalized in `storage_classes.md` §5.6: a per-run bulk producer owns its teardown. Run scratch ≈ 18 GB/engine-hour; the bulk-store size watch is BUILT (fractal-storage owns it); an in-run pruner inside `steered_frontier` remains the named durable follow-on if the watch ever fires.
- **Cross-run saturation memory — LIVE.** The ledgers ARE the cross-run memory, identity-aware, breadth-leg within-partition only; mechanism/constants → `discovery_pipeline.md` §5. **Run-25 first exercise: 8.81% discounted vs the 31.1% calibration projection — different estimands (leave-one-run-out vs one run's stream; quote §5.2 as a bound, not a prediction) — and `julia:multibrot3/4/5` exactly 0 of 6,999, the designed negative result** [tracked: `data/discovery/prod25_20260809/summary.json`].
