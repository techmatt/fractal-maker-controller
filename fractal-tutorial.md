## EXTRACTION CAUTIONS (for every future transfer prompt)
- ★★ **Committed CORN score files hold CONDITIONAL sigmoids** — unconditional P(≥k) is the running product; bare-sigmoid reads understate sparse cutpoints by whole points of AUC (full rule → fractal-models). Product-read both sides of any comparison.
- ★★ **A blind sheet's base rate is NOT the training base rate** — blind_minibrot is 3.95× enriched at ≥4. A calibration arm must target the head's own corpus; targeting an enriched sheet writes an unsatisfiable bar. Corollary: **pre-registered bars get a self-test — the bar must pass the head it was built from.**
- ★★ **The export join must carry EVERY image-determining axis** — sweeps (opacity, threshold, rolloff) are the picture, not variations; verify by picture count, and `renders verify` (regenerate vs judged, re-compression yardstick) is the standing pattern that catches what row counts cannot.
- ★★ **Select training epochs on a PROPER SCORING RULE (validation loss), never a rank statistic** — AP rated a collapsed checkpoint (mean P(≥2)=0.002 on a 78%-positive slice) ABOVE the sound one; training-mode loss hides BN collapse (batch statistics stand in for the broken running ones), so the collapse exists only at deploy. And the escalation is not free: a proper rule optimizes order AND scale, so it maximizes neither — report the whole band.
- ★★ **The old crate's Rust auto-maxiter is STALE**; truth = `tools/scoring/production_pins.py`: `clamp(4000·(1 + 0.30·log₂(3.0/fw)), 200, 67000)`. Rule generalizes: when Python and Rust both hold a constant, the Python pin is deployed truth.
- ★ **Old engine truncates decimal→f64** (~1 ulp); attribute parity residue by re-rendering with the truncated constant before suspecting a real bug.
- ★ Old smooth coloring is TWO paths; comparisons drive the old engine with `--coloring '{"field":"smooth"}'`.
- ★ Cyclic colormaps in the old library omit their closing stop; make it explicit on transfer (a cyclic map closes on the colour it opened with; a sequential one runs end to end). `blue_orange` lives ONLY in `vivid_blue_orange.json`.
- ★ One legacy source batch wrote julia seed coords as JSON NUMBERS (290 rows) — coerce at the adapter and COUNT the coercions.
