## Caveats that would cause a misread
- **No head ever scores the wallpaper that ships** — judges read the 640×360 candidate; a release row is a COLD render with autolevel INSIDE it. ⚠ **A depth row's stored picture is the LEVELLED picture the judge scored; a re-render derives a different curve** (`acted_unrecoverable`; populations → fractal-engine). ⚠ **A reader that takes a seat's mode off `gallery.jsonl` gets the ROUTED mode — render at `recipe["mode"]`** (a `smooth` re-render of 17 `itinerary` seats once read as "stale files"). ⚠ **The rank key reads `flatness`, so every seating is BUSIER than the pool by construction** (dead-space <0.05: 24% of pool, 62% of seats) — intentional (Matt, ckpt 107).
- Every location in a run is attempted 1 smooth + 2 strange; pools DISJOINT per KIND; **under-fill is the strange bar.**
- ⚠ A RESUME REPLACES the CURATION run record WHOLESALE; harvest `--minutes` = ACTIVE time; check the pool size on the record before trusting last week's figure.
- **★ LIBRARY ≠ DRAWABLE** — palettes → `palettes/README.md`; **never merge a pair marked DIFFERENT**; the palette head PICKS in the production loop; `blue_orange`: Matt's eye is calibrated on the FOLDED ramp.
- ⚠ **`renders.job_name` digests the CHECKOUT path** (→ fractal-engine). ⚠ **BOX MEMORY IS COMMIT CHARGE AND LEAKS** — the one-pool-per-box rule reaches across repos; a lane runs AFTER a pool-holding leg, never beside (a streaming leg such as a votes build is not one — a lane ran green beside it). **A prompt that stops a leg kills its OWN workers by pid, never every `fractal-engine.exe` on the box** (a website rig did, mid-pytest next door, ckpt 106).
