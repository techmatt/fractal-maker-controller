## The label corpus — read before counting anything
**Canonical reader = `label_store.resolve_score` — never write another, never infer labeling state from `images.jsonl`.** Labels live in three registered places (in-store `images.jsonl` + `labels/*.json` sidecars + the amendment overlay); never-delete, committed; `decoded_class` ≠ human label; location label = max over crops. **Census 2026-08-07: 37 batches / 14,339 rows / 12,637 labeled / 1,702 registered-unlabeled (1,157 = the revision sitting — unlabeled BY DESIGN, verdicts in the overlay); by score 1:6,455 · 2:3,424 · 3:2,086 · 4:672.** Stage-2 corpora → fractal-emission; window corpus 3-way STRING classes, never pooled with location rows (separation keyed by registration).
- **★ `labels/` holds ONLY label-corpus sidecars** — `load_sidecar` walks every `labels/*.json`; a foreign-schema file is a loud red. Non-corpus judgment records live under `data/`.
- **★★ The scale is 1–4. Class 4 = "exceptional wallpaper emission"** — preferred where available, NOT a new floor. **Class 4 is JUST A CLASS (Matt, firm)**: no special case, no separate threshold, no per-family calibration; short of training data → harvest and label more. The written class-4 rubric is RETIRED — the anchor sheets are the bar.
- **★★ The amendment overlay.** `resolve_score` prefers a revision; originals never modified; revisions → per-source `amend_<batch>.json`; **the split is MANDATORY** (in-row filling double-counts each source against its anchor twin); a revision batch shows null in its own `images.jsonl` — expected. **Every training consumer routes through the overlay — enforced** [code: `corpus_reader.iter_labeled` choke-point + GATE 9].
- `image_id` collides across scale batches — `resolve_score` joins on `join_key`. ⚠ Three render regimes in the corpus — **Matt: the labels hold; not to be raised.**
- **★★ `loc_id` stability is a silent-failure seam** — the aug cache maps `loc_id` → coordinates; a renumbering rebuild points every tile at the wrong location and training still completes plausibly. **Any rebuild asserts tile↔location agreement in BOTH directions first.** A re-split invalidates the cache — a ~3 h cost, no longer a one-way door.
- **`atom_key` IS `snapped_dedup_key(render.cx, render.cy, degree)`** [verified at the v11 manifest — identity work, +0 merges].
- ⚠ **Opaque-keyed sheet exports are INVISIBLE to `test_label_reachability`** — verify merges by row count, never by the guard (gap open).

## Sampling regime — the rules
- **★★ The disqualifying bias for an EVAL set is MODEL-DRIVEN SELECTION, not non-randomness** — a systematic grid, ladder or base-rate draw is eval-eligible; candidates a model scored well are not.
- **★★ Split registry = `tools/scoring/batch_registry.py`, the SINGLE owner** — FAIL-CLOSED: unregistered ⇒ biased/train; contradiction ⇒ hard abort ⇒ **register a new generation method BEFORE its batch is built, or it silently lands train-side.**
- **★★ Score-unconditioned eval instruments are EXEMPT from the forced-eval group cascade (Matt)** — flag is data on the registration; biased group-mates stay TRAIN. Caveat (protocol §2): model reads on those legs are mildly optimistic — fine for base rates, NEVER for fine AUC. Split-group unioning includes SHARED MINIBROT ATOM as a seed.
- **★ Nominal splits are not realized splits** — check realized shares before quoting a CI.
- **★★ v11 CALIBRATED ON RANDOMIZED LOCATION-GROUPED SPLITS, eval share 20% — the shared default everywhere.** **★ THE PHOENIX GROUPING FIX IS A PERMANENT RULE: group by the EXACT non-`c` axes, never by seed-`c` alone** — seed-c-alone made a whole plane grid ONE spatial group. Any family swept at a fixed parameter point has this failure available.

- **★★ CORRECTION SHEETS are the sitting default (Matt):** the relevant head pre-labels, presentation **SORTED good→bad by the head's score** (not shuffled), suggestion prefilled, accept-all-below sweep behind confirm; unreviewed suggestions never leave the page as labels. No blind rows, no calibration aids (firm). Correction sheets serve off registered batches via the rig, never `build_combined_label_sheet` (its every property is the negation — guard checks both paths). ## Label noise — what it forbids
Disagreement is adjacent-category only: a real ordinal scale with a fuzzy boundary, not a learnability ceiling. **Forbids: reading small AUC differences on the ≥3 boundary.** Pre-register bars before computing; verify the instrument's inputs actually change (`measurement_practice.md`). **Matt: "noise is expected at all boundaries" — do not re-raise.**
