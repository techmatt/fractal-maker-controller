## Laws
- **★★★ A LABEL ROW CARRIES ITS JOIN.** Label + complete render block/params in the SAME tracked row; a label keyed on an id whose meaning lives in an untracked file is orphaned when that file dies (proven three times). Labels ship FLAT: label + join + batch id + registration flags; eligibility DERIVED, never stored per-row.
- **Export/ingest discipline:** the `labels\` drop is untracked — **THE INGESTED STORE IS THE COMMITTED RECORD; ritual = export → ingest in the SAME session.** ONE path (`label ingest` → intake.run), count-verified, idempotent, append/overlay-only, both stores; the pin is asserted BEFORE and after the write [code: intake.py `assert_pin` on `landing` and `landed`, ckpt 76]. Sheet units are numbered by position and join through `artifacts/sheet/` — a rebuilt sheet renumbers.
- **Canonical reader = `store.resolved()` / `finished.resolved()`** [code: labeling/store.py] — never write another, never infer labeling state from raw image lists. Originals never modified; a revision is a later row, LATEST-WINS by `(recorded_at, file, line)` — `labeler` is not in the key. The maker-era amendment overlay was applied ONCE at `corpus_import`; no overlay exists in this repo.
- **★★ THE SCALE IS 1–4 FOR EVERY HEAD; class 4 is just a class.** Anchor sheets DEFINE each bar (the ckpt-51 sitting's anchors = the strange 4 bar). **Store scale is DECOUPLED from model class count** [code: finished.SCALE · RECIPES · finished_import.SOURCE_SCALE; pin = config-vs-recipe + config-vs-checkpoint-width, asserted per-run; a recipe that cannot express a population verdict REFUSES to train]. Imported rows' ceiling sits on SOURCE_SCALE; 145 of the strange store's 3,322 rows are tier 4, none imported.
- Location label = max over crops; `decoded_class` ≠ human label. Multiple render regimes coexist — the labels hold.
- **★★ `labeler:null` = MATT'S LABELS** (maker-era import with the field absent); Matt is the ONLY human labeler. **Label-origin rules protect exactly two things — eval-split integrity and taste attribution; when neither is in play, a label is a label.**
- **Any row with `scores.p_ge4 == null` is on the retired 3-class scale — evidence of nothing current** (125 such strange rows gained a P(≥4) at the ckpt-76 rescore; the law stands for the rest).

Laws that still change a read:
- **★★ The disqualifying bias for an EVAL set is MODEL-DRIVEN SELECTION, not non-randomness** — a systematic grid or base-rate draw is eval-eligible; candidates a model scored well are not. **★ Nominal splits are not realized splits** — check realized shares before quoting a CI. ## Judge method (governs every retrain)
- **★★ THE WINNER RULE:** candidate only if (a) no overall pre-declared metric significantly worse (95% paired bootstrap) AND (b) the motivating slice significantly better, none worse; declare slices before numbers. **The raw scoring-rule arm STANDS (ckpt 76): it caught a mis-launched band; a scale-only failure with order intact is a CAPACITY/RECIPE signal before it is a data signal — check the realized recipe before explaining the numbers.**
- **★★ NON-INFERIORITY READS THE BAND:** for parity-motivated candidates the bar is "no pre-declared metric significantly worse ON THE BAND"; a per-seed conjunction is a multiplicity trap — any future per-seed conjunction must PRE-STATE its false-alarm size at registration. **★★ Cross-seed comparisons score the BAND, never the staged pick alone.** **★★ The model-selection objective is a CONTROLLED VARIABLE** — freeze selection to the baseline-comparable population; amendment before the re-run. **★★ CORN scale is train-prior-calibrated** — a retrain moves the whole probability scale (restatement modes → fractal-operating); the ckpt-76 re-fit split its causes (rows vs scale) by re-fitting the retired artifact over the grown stores first — do that every adoption.
- **★★ A DECLARED RECIPE THE LAUNCH DOESN'T READ IS NOT THE RECIPE** [guards: `check_declared_backbone` at launch · `check_written_backbone` in `render_acceptance.read`; `render_train.MISLAUNCHED` holds the three medium runs, out of every band]. Every record in a run dir agreed with the wrong value; the tell was artifact SIZE (17.2 MB vs 5.1 MB) — compare a shipped artifact's size to its predecessor's as a free check.
- **A head's render cache must be COMPLETE against its stored rows before it trains** [code: `renders plan` / `renders build`]. The location head is REGIME-ROBUST (`seed0_all_regimes`, `f8f80511`, weights-v2, adopted 2026-08-20; flip rate 4.56% pooled / 1.58% on the great cut): **one score SCALE across regimes, not one NUMBER** — never read a cross-regime delta ≤0.3 as a model change; regime is PROVENANCE, not semantics. **A prereg's POPULATION is load-bearing** — measure a decision on the population it serves.
- **Division of labor:** the location head STEERS within-family and NEVER ranks cross-family (and now picks FRAMING within one location — → fractal-discovery) · **ONE render judge (`render`, weights-v4 since ckpt 76)** scores FINISHED renders of both kinds · the palette head picks palettes within a location, never quality · steer/rank/select stay split. **smooth/strange are KINDS**; `smooth_render`/`strange_render` name the two LABEL STORES (two corpora, two blind instruments, two base rates, two floors) but no model. **A shared nominal scale does NOT license cross-kind ranking** — pools disjoint, floors per kind. Two training runs at once ≈1.7× throughput (data-loading bound).
- **Correction loop = the labeling method.** Mechanics → `labeling/README` [code: labeling/sheets.py]. Laws kept here: suggestions come from the SHIPPED `render` head (all seven load sites resolve through `floors.SCORING_HEAD` — re-check after any judge adoption) · sheets are cut ORDERED BY P(≥4) (P(≥3) saturates at the end a sheet is read from) · **~500 rows per sitting, then VERIFY the labels earned their keep before more**; glance sheets/galleries sized likewise · anchor first for a fresh scale · a stated RULE answers a unit BEFORE it renders; rule verdicts stay DERIVED, never stored; **never pool readouts across rule ids** (81 maker-era `rule:interior_gt30_v1` rows) · sheet render cost tracks GATE STATUS + DEGREE, never maxiter or pixel count — **pilot per-class ON the target population** · per-sitting correction rate = the head's report card (rare-color sitting: 44.8% smooth / 33.3% strange, CEILINGS); on modes a head has never seen, agreement is NOISE.

## Label noise — what it forbids
Disagreement is adjacent-category only (the store's 12 superseded pairs all differ by one class): a real ordinal scale with a fuzzy boundary, not a learnability ceiling. **Forbids reading small AUC differences on the ≥3 boundary.** Pre-register bars before computing; verify the instrument's inputs actually change.
