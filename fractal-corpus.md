## Laws
- **★ A LABEL ROW CARRIES ITS JOIN.** Label + complete render block in the SAME tracked row; labels ship FLAT; eligibility DERIVED, never stored; no path, so no `artifacts/` delete can reach a row [`finished.check` refuses a row with no `render_key`; `test_history_purity.py` bans absolute paths].
- **★ ⚠ THE LABEL STORES AND THE CANDIDATE LEDGER BARELY OVERLAP, BY PLACE AND NOT BY KEY** — join ceiling ~12%; a geometry-blind key recovers ZERO (tombstoned). Quote the RATIO, never counts. **The rows that DO join are the SELECTED TOP** — a standing caveat on every read off them.
- **★ A ROW LANDS IN THE STORE ITS MODE — AS ROUTED — SENDS IT TO** [`finished.routed_to` CALLS `hunt.kind_of` (`hunt.kind_of:960`); `finished.routes_to` reads the `texture_flat` register]. **A flat-texture modulate row is SMOOTH (ckpt 94).** ⚠ Three re-routed rows stand at places `smooth_render`'s pinned set holds — a future smooth-store batch re-rendering one would be TRESPASS; check first.
- **Export/ingest:** `labels\` is untracked — **THE INGESTED STORE IS THE COMMITTED RECORD; ritual = export → ingest in the SAME session**, count-verified, both stores, pin asserted before and after [`finished.assert_pin_holds`, injected at `labeling/intake.py`]. Ingest OLDEST DROP FIRST; a drop's name carries the BATCH, not the sheet directory (a re-cut shares its path — delete a superseded cut; the only tell is a unit count). Mechanics → `labeling/README.md`.
- **Canonical reader = `store.resolved()` / `finished.resolved()`** [`test_label_store.py`, `test_finished_store.py`] — never write another. Originals never modified; a revision is a later row, LATEST-WINS by `(recorded_at, file, line)`; `labeler` is not in the key.
- **★ THE SCALE IS 1–4 FOR EVERY HEAD; class 4 is just a class.** Anchor sheets DEFINE each bar; store scale is DECOUPLED from model class count [`finished.py`, `finished_train.py`, `finished_import.py`, `finished_acceptance.py`]. Location label = max over crops; `decoded_class` ≠ human label. ⚠ No label row carries a `scores` column — a `scores.p_ge4` filter is a no-op and a candidate-pool fact.
- **★ `labeler:null` = MATT'S LABELS**; Matt is the ONLY human labeler. Label-origin rules protect exactly eval-split integrity and taste attribution; otherwise a label is a label.
- **★ LABELING IS AFFORDABLE WHEN WE NEED IT** — size for power; renders price a batch. **★ LABELS MUST SERVE OBJECTIVES THE NEXT RETRAIN CANNOT DEPRECATE** — eval instruments, design reads, correction sittings pass; training volume fails by default. ## Sampling regime
Split-registry rulings → `settled_rulings.md §Corpus sampling`. What still changes a read:
- **★ The disqualifying bias for an EVAL set is MODEL-DRIVEN SELECTION, not non-randomness.** Nominal splits are not realized splits. **Eligibility derives from THREE fields: `eval_only or (score_unconditioned and not anchored)`** [`registry.py:105`; `test_label_registry.py`, `test_eval_pins.py`]; `eval_only` is a PIN and OUTRANKS. Register a generation method BEFORE its batch is built; caveats → `data/batch_caveats.md`.
- **★ ⚠ REGISTRATION ALONE DOES NOT PIN.** The pin is `eval_split.jsonl`; `label ingest` never refreshes it. `pins.every_pinned` (union over every store, 1,452 places) vs `pins.pinned` (location store alone, 1,002); the reframe channel refuses a pinned place as seed AND frame [`test_reframing_channel.py`]. **Fix the split, never the pin**; `write_pin` TRUNCATES. ⚠ The guards catch CONTRADICTION and OMISSION, not correction.
- **★ A BLIND SHEET INFORMS EXACTLY ONE BOUNDARY**; blind sheets are eval-only forever; a rate off any prefilled sheet is a CEILING. Standing instruments: blind_minibrot (≥4; 197 rows, 186 from ONE maker production-walk ledger; **48.7% q4 is the base rate the reframe channel is read against**) · blind_modes (≥2/≥3 freely; **≥4 has zero blind positives — NEVER read it** [`test_eval_pins.py`]). ⚠ smooth ≥4 order on blind_minibrot is ≈ chance for both render judges — eyeball seats before building an instrument; the LOCATION head ranks its own q4 nuclei in-sample (median P(≥4) 0.843). Nothing covers smooth ≥3; **phoenix:classic holds 73 labels, 7 q3+, 1 q4, one batch (`gather_v6`)** — a seed set, not a supply; its base rate is unbuilt.

## Judge method — reading caveats only (the method → `preserve\judge_training.md`)
- **★ THE RENDER JUDGE IS A GATE, NOT A TOP-END RANKER.** Inside `P(≥4) ∈ [0.60, 0.95)` it barely orders Matt's 3-vs-4; unbanded it orders at `AUC(≥4)` 0.650 — what resists is ordering INSIDE its own uncertainty band. At matched score a composite is likelier to be a 4 than a thin-colour candidate, so **relaxing a bar for a thin cell compounds the error.**
- **★ THE `P(≥4)` COLUMN IS A WELL-CALIBRATED ≥3 SCREEN WEARING A ≥4 NAME.** No threshold on it buys tier-4 precision; every threshold buys ≥3 purity. **A themed leg reads its yield at `P(≥3) ≥ 0.50`.** ⚠ A map's prior label history splits by store (helps smooth, HURTS strange); the pooled reading is INVALID. **★ `P(≥4) ≥ 0.5` IS TRUSTED AS A QUALITY GATE (Matt, 2026-09-02)** — he raises quality issues himself.
- **★ THE RENDER JUDGE IS NOT REGIME-ROBUST.** Fit and read on the LABEL-GEOMETRY column, never the candidate one. The location head is REGIME-ROBUST in the opposite sense: one score SCALE, not one NUMBER — never read a cross-regime delta ≤0.3 as a model change.
- **★ THE MEASURED CROSSOVERS AND THE ACTING BAR ARE DIFFERENT NUMBERS.** `MEASURED_RELEASE_FLOORS` are isotonic fits per KIND; only the strange one gates anything, at a run's release. The POOL bar is a flat `0.50` — ruled round (Matt, ckpt 98): with enough locations mined the cutoff stops mattering.
- Committed CORN score files hold UNCONDITIONAL P(≥k). **Division of labor:** location head STEERS within-family, picks FRAMING within one location · ONE render judge scores both kinds · palette head picks palettes within a location; steer/rank/select stay split. **smooth/strange are KINDS**; a shared nominal scale does NOT license cross-kind ranking.

## Sittings — the correction loop IS the labeling method
Mechanics → `labeling/README.md`; assume proper randomization. Suggestions come from the SHIPPED head via `floors.SCORING_HEAD` — re-check every load site after a judge adoption. Sheets are cut ORDERED BY P(≥4), pre-labeled, sorted good→bad (default), ~500 rows a sitting; VERIFY the labels earned their keep. A stated RULE answers a unit BEFORE it renders; rule verdicts DERIVED, never pooled across rule ids. Per-sitting correction rate is the head's report card and a CEILING; on unseen modes agreement is NOISE.
- **★ A sheet is ALWAYS a fresh render at `sheets.LABEL_RESOLUTION`** (the single spelling); score every sheet picture at label geometry too and carry BOTH readings. Cost tracks GATE STATUS + DEGREE — pilot per-class ON the target population. **★ ⚠ AUTOLEVEL IS INVISIBLE ON THE ROW** — measure a pool sheet at label geometry BEFORE building it.
- **★ ONE POPULATION SPANNING BOTH KINDS IS TWO SHEETS** (`finished.check` routes by `hunt.kind_of`). ⚠ `finished_source` writes `facts`, `columns` and a caption UNCONDITIONALLY — rewrite `sheet.jsonl` with them emptied for a blind sheet. ⚠ `--port` walks upward — read the banner.
- **★ A SHEET SHOWS ONE RESULT PER LOCATION (Matt)** — label-harvest legs want BREADTH at low k; seat legs want DEPTH at high k. **★ WHEN THE OBJECTIVE IS HARVESTING q3/q4 IN SPARSE MODES, LABEL THE BEST ONLY (Matt).** Look-first, label-on-divergence (ckpt 98).
