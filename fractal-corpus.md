## Laws
- **★★★ A LABEL ROW CARRIES ITS JOIN.** Label + complete render block/params in the SAME tracked row; a label keyed on an id whose meaning lives in an untracked file is orphaned when that file dies (proven three times). Labels ship FLAT: label + join + batch id + registration flags; eligibility DERIVED, never stored per-row.
- **Export/ingest discipline:** the `labels\` drop is untracked — **THE INGESTED STORE IS THE COMMITTED RECORD; ritual = export → ingest in the SAME session**, count-verified, both stores, pin asserted before and after [code: intake.py `assert_pin`]. Sheet units are numbered by position — a rebuilt sheet renumbers.
- **Canonical reader = `store.resolved()` / `finished.resolved()`** [code: labeling/store.py] — never write another, never infer labeling state from raw image lists. Originals never modified; a revision is a later row, LATEST-WINS by `(recorded_at, file, line)` — `labeler` is not in the key. No amendment overlay exists in this repo (the maker-era overlay was applied ONCE at `corpus_import`).
- **★★ THE SCALE IS 1–4 FOR EVERY HEAD; class 4 is just a class.** Anchor sheets DEFINE each bar (the ckpt-51 sitting's anchors = the strange 4 bar). Store scale is DECOUPLED from model class count [code: finished.SCALE · RECIPES · finished_import.SOURCE_SCALE; pin asserted per run; a recipe that cannot express a population verdict REFUSES to train]. Imported rows' ceiling sits on SOURCE_SCALE.
- Location label = max over crops; `decoded_class` ≠ human label. Multiple render regimes coexist — the labels hold.
- **★★ `labeler:null` = MATT'S LABELS** (maker-era import); Matt is the ONLY human labeler. **Label-origin rules protect exactly two things — eval-split integrity and taste attribution; when neither is in play, a label is a label.**
- **Any row with `scores.p_ge4 == null` is on the retired 3-class scale — evidence of nothing current.**
- **★★ LABELING IS AFFORDABLE WHEN WE NEED IT** — size for power; renders, not labeling, price a batch (~6.3 rows/min labeled). **★★ LABELS MUST SERVE OBJECTIVES THE NEXT RETRAIN CANNOT DEPRECATE** — eval instruments, design reads, correction sittings pass; training volume fails by default. ## Judge method (governs every retrain)
- **★★ THE WINNER RULE:** candidate only if (a) no overall pre-declared metric significantly worse (95% paired bootstrap) AND (b) the motivating slice significantly better, none worse; declare slices before numbers. **The raw scoring-rule arm STANDS (ckpt 76): a scale-only failure with order intact is a CAPACITY/RECIPE signal before it is a data signal — check the realized recipe before explaining the numbers.**
- **★★ NON-INFERIORITY READS THE BAND:** for parity-motivated candidates the bar is "no pre-declared metric significantly worse ON THE BAND"; a per-seed conjunction is a multiplicity trap — any future per-seed conjunction PRE-STATES its false-alarm size at registration. **★★ Cross-seed comparisons score the BAND, never the staged pick alone.** **★★ The model-selection objective is a CONTROLLED VARIABLE** — freeze selection to the baseline-comparable population; amendment before the re-run.
- **★★ CORN scale is train-prior-calibrated** — a retrain moves the whole probability scale. **TWO RESTATEMENT MODES when a cut must survive a head flip:** VOLUME-MATCHED (same fraction of a fixed reference pool) · HUMAN-DERIVED CROSSOVER (isotonic P(≥boundary)=0.5 on a labeled sheet; the volume change can BE the finding). Every adoption splits its causes (rows vs scale) by re-fitting the retired artifact over the grown stores first.
- **Test construction:** a reproducibility test re-runs the writer the artifact came from; NEVER construct a test's expected value with the transform under test — a planted red proves the guard bites; a pre-declared bar must OUT-RESOLVE its instrument — a teacher's self-agreement is a ceiling, never a bar.
- **The declared-recipe law** (→ fractal-operating) is GUARDED here [code: `check_declared_backbone` at launch · `check_written_backbone` in `render_acceptance.read`; `render_train.MISLAUNCHED` holds the three medium runs, out of every band]; compare a shipped artifact's size to its predecessor's as a free check.
- **A head's render cache must be COMPLETE against its stored rows before it trains** [code: `renders plan` / `renders build`]. The location head is REGIME-ROBUST (`seed0_all_regimes`, `f8f80511`, weights-v2, adopted 2026-08-20): **one score SCALE across regimes, not one NUMBER** — never read a cross-regime delta ≤0.3 as a model change (→ fractal-discovery §Regime law). **A prereg's POPULATION is load-bearing** — measure a decision on the population it serves.
- **Division of labor:** the location head STEERS within-family and NEVER ranks cross-family (and picks FRAMING within one location → fractal-discovery) · **ONE render judge (`render`; identity and tag → fractal-tutorial)** scores FINISHED renders of both kinds · the palette head picks palettes within a location, never quality (its split keys on LOCATION — settled) · steer/rank/select stay split. **smooth/strange are KINDS**; `smooth_render`/`strange_render` name the two LABEL STORES (two corpora, two blind instruments, two base rates, two floors) but no model. **A shared nominal scale does NOT license cross-kind ranking** — pools disjoint, floors per kind. Two training runs at once ≈1.7× throughput (data-loading bound).
- **★★ THE CORRECTION LOOP IS THE LABELING METHOD** (mechanics → `labeling/README.md`; assume proper randomization — a distribution concern is ≤1 line). Laws kept here: suggestions come from the SHIPPED `render` head via `floors.SCORING_HEAD` — re-check every load site after any judge adoption · sheets are cut ORDERED BY P(≥4) · **~500 rows per sitting, then VERIFY the labels earned their keep** · anchor first for a fresh scale · a stated RULE answers a unit BEFORE it renders, rule verdicts DERIVED never stored, **never pool readouts across rule ids** · sheet render cost tracks GATE STATUS + DEGREE, never maxiter or pixel count — **pilot per-class ON the target population** · per-sitting correction rate = the head's report card (a CEILING); on modes a head has never seen, agreement is NOISE.
