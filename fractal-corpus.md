## Sampling regime
- **★★ The disqualifying bias for an EVAL set is MODEL-DRIVEN SELECTION, not non-randomness** — a systematic grid or base-rate draw is eval-eligible; candidates a model scored well are not.
- **★★ Split registry is the SINGLE owner, FAIL-CLOSED:** unregistered ⇒ biased/train [code: registry.UNREGISTERED]; contradiction ⇒ hard abort [guard: `registry.read` + test, ckpt-75 follow-up — until it lands, a later row silently REPLACES an earlier one] ⇒ **register a new generation method BEFORE its batch is built.** All migrated maker batches are train-side. **The in-repo registry is the authoritative roster; its caveats live in `data/batch_caveats.md` — cite, never restate.**
- **★★ Score-unconditioned eval instruments are EXEMPT from the forced-eval group cascade** — biased group-mates stay TRAIN; fine for base rates, NEVER for fine AUC. **★ Nominal splits are not realized splits** — check realized shares before quoting a CI.
- **★★ Location-grouped randomized splits are the default; group by the EXACT non-`c` axes, never seed-`c` alone.**
- **★★ §2a — contradicting stamped splits force a GLOBAL re-derivation** (or a frozen authority protecting an incumbent's eval). **§2b — anchored correction-sheet labels are TRAIN-SIDE ONLY, per head.** **★★ THE EVAL-ONLY PIN outranks §2a**, wired at UNIT granularity; trainers assert on the c-INCLUSIVE coordinate, never `image_id`.
- **★★ A BLIND SHEET INFORMS EXACTLY ONE BOUNDARY, chosen by its draw's quality conditioning.** Blind sheets are eval-only forever. Anchored sheets measure AGREEMENT with the incumbent; a rate off any prefilled sheet is a CEILING.
- **Standing blind instruments (data):** blind_minibrot (≥4; its ≥3 rate is the GATED intake's base rate) · blind_modes (gate ≥2/≥3 freely; **≥4 has zero blind positives — NEVER read it; guarded in the suite**). No instrument covers smooth ≥3 or a phoenix:classic base rate — build one WHEN a decision needs it, never before.

## Judge method (governs every retrain)
- **★★ THE WINNER RULE:** candidate only if (a) no overall pre-declared metric significantly worse (95% paired bootstrap) AND (b) the motivating slice significantly better, none worse; declare slices before numbers.
- **★★ NON-INFERIORITY READS THE BAND:** for parity-motivated candidates the bar is "no pre-declared metric significantly worse ON THE BAND"; a per-seed conjunction is a multiplicity trap — any future per-seed conjunction must PRE-STATE its false-alarm size at registration. **★★ Cross-seed comparisons score the BAND, never the staged pick alone** (a pick that spends a selection set leaves the band as the honest read). **★★ The model-selection objective is a CONTROLLED VARIABLE** — freeze selection to the baseline-comparable population; amendment before the re-run. **★★ CORN scale is train-prior-calibrated** — a retrain moves the whole probability scale (restatement modes → fractal-operating; conditional-sigmoid caution → fractal-tutorial).
- **A head's render cache must be COMPLETE against its stored rows before it trains** [code: `renders plan` / `renders build`]. The location head is REGIME-ROBUST (ckpt 59; three regimes cached complete under regime-addressed tile identity): **one score SCALE across regimes, not one NUMBER** — never read a cross-regime delta ≤0.3 as a model change; regime is PROVENANCE, not semantics. Lesson: **a prereg's POPULATION is load-bearing** — measure a decision on the population it serves; train rows flatter any cross-regime consistency metric.
- **Division of labor:** the location head STEERS within-family and NEVER ranks cross-family · **ONE render judge (`render`, ADOPTED ckpt 72)** scores FINISHED renders of both kinds · the palette head picks palettes within a location, never quality · steer/rank/select stay split. **smooth/strange are KINDS** (`smooth` = one mode; strange = the other 17 production modes); `smooth_render`/`strange_render` name the two LABEL STORES (two corpora, two blind instruments, two base rates, two floors) but no model. **A shared nominal scale does NOT license cross-kind ranking** — pools disjoint, floors per kind.
- **Correction loop = the labeling method.** Mechanics → `labeling/README` [code: labeling/sheets.py] (home confirmed by the ckpt-75 audit). Laws kept here: suggestions come from the SHIPPED `render` head (the sheet cutter silently loaded retired judges once — re-check after any judge adoption) · sheets are cut ORDERED BY P(≥4) (P(≥3) saturates at the end a sheet is read from) · **~500 rows per sitting, then VERIFY the labels earned their keep before more**; glance sheets/galleries sized likewise · anchor first for a fresh scale · a stated RULE answers a unit BEFORE it renders; rule verdicts stay DERIVED, never stored; **never pool readouts across rule ids** (the store holds 81 maker-era `rule:interior_gt30_v1` rows) · sheet render cost tracks GATE STATUS + DEGREE, never maxiter or pixel count — **build budgets do not transfer across populations; pilot per-class ON the target population** · per-sitting correction rate = the head's report card; on modes a head has never seen, agreement is NOISE.
- Re-rating evidence: the store's 12 superseded pairs all differ by exactly one class (4→3) — the only in-store support for "adjacent-category only", thin-n.
