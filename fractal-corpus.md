## Laws
- **★ A LABEL ROW CARRIES ITS JOIN.** Label + complete render block/params in the SAME tracked row; a label keyed on an id whose meaning lives in an untracked file is orphaned when that file dies (proven three times). Labels ship FLAT — label + join + batch id + registration flags; eligibility DERIVED, never stored per-row; no path, so no `artifacts/` delete can reach a row [ENFORCED: `finished.check:247` refuses a row with no `render_key`; `test_history_purity.py:182` bans absolute paths in tracked records].
- **★ ⚠ THE LABEL STORES AND THE CANDIDATE LEDGER BARELY OVERLAP, BY PLACE AND NOT BY KEY.** Most labeled rows sit at a place that never became a candidate or a family the ledger lacks; the reader-side join ceiling is ~12% and a correctly built geometry-blind key recovers ZERO rows (tombstoned). ⚠ Quote the RATIO, never the counts — both stores grow every sitting. **The rows that DO join are the SELECTED TOP** (tier-4 share nearly triple the rest) — a standing caveat on every read off them.
- **Export/ingest:** the `labels\` drop is untracked — **THE INGESTED STORE IS THE COMMITTED RECORD; ritual = export → ingest in the SAME session**, count-verified, both stores, pin asserted before and after [ENFORCED: the function is `finished.assert_pin_holds` (`finished.py:490`), injected as the `assert_pin` field at `labeling/intake.py:249,262`]. Sheet units are numbered by position — a rebuilt sheet renumbers. **★ INGEST OLDEST DROP FIRST** — the no-op test reads what the store CURRENTLY says, so a newer-then-older order writes stale rows back on top and reverts revised renders. **★ ⚠ A DROP'S NAME CARRIES THE BATCH, NOT THE SHEET DIRECTORY** — a re-cut shares one drop path with the cut it replaced, and joining against the STALE sheet is *accepted*: plausible counts, rows bound to the WRONG pictures. The only tell is a unit count; delete a superseded cut.
- **Canonical reader = `store.resolved()` / `finished.resolved()`** [ENFORCED: `store.py:355`, `finished.py:447`; `test_label_store.py`, `test_finished_store.py`] — never write another, never infer labeling state from raw image lists. Originals never modified; a revision is a later row, LATEST-WINS by `(recorded_at, file, line)`; `labeler` is not in the key. No amendment overlay in this repo.
- **★ THE SCALE IS 1–4 FOR EVERY HEAD; class 4 is just a class.** Anchor sheets DEFINE each bar. Store scale is DECOUPLED from model class count [ENFORCED: `finished.py:111`, `finished_train.py:99`, `finished_import.py:260,550`; a recipe that cannot express a population verdict refuses at `finished_acceptance.py:194`]. Imported rows' ceiling sits on SOURCE_SCALE.
- Location label = max over crops; `decoded_class` ≠ human label. Multiple render regimes coexist — the labels hold. ⚠ **No label row carries a `scores` column at all** — re-measured true at ckpt 92 across `data/{smooth,strange}_render/rows/`, unenforced by design — so a `scores.p_ge4` filter is a no-op and a candidate-pool fact, never a training filter.
- **★ `labeler:null` = MATT'S LABELS**; Matt is the ONLY human labeler. **Label-origin rules protect exactly two things — eval-split integrity and taste attribution; when neither is in play, a label is a label.**
- **★ LABELING IS AFFORDABLE WHEN WE NEED IT** — size for power; renders, not labeling, price a batch. **★ LABELS MUST SERVE OBJECTIVES THE NEXT RETRAIN CANNOT DEPRECATE** — eval instruments, design reads, correction sittings pass; training volume fails by default. Never add calibration duplicates, drift probes, or repeat rows (settled). Don't editorialize on a sheet about to be labeled blind. A prompt running while Matt labels conflicts on GIT, not CPU.

## Sampling regime
Split-registry rulings are SETTLED → `settled_rulings.md` §Corpus sampling [code: registry.UNREGISTERED · registry.refuse_contradiction]. What still changes a read:
- **★ The disqualifying bias for an EVAL set is MODEL-DRIVEN SELECTION, not non-randomness** — a systematic grid or base-rate draw is eval-eligible; candidates a model scored well are not. **Nominal splits are not realized splits** — check realized shares before quoting a CI. **Eligibility is DERIVED from THREE fields: `eval_only or (score_unconditioned and not anchored)`** [ENFORCED: `registry.py:98`; `test_label_registry.py`, `test_eval_pins.py`]; `eval_only` is a PIN and it OUTRANKS — both shipped instruments are eligible solely by it. Register a new generation method BEFORE its batch is built; caveats → `data/batch_caveats.md`.
- **★ ⚠ REGISTRATION ALONE DOES NOT PIN.** The pin is `eval_split.jsonl` and `label ingest` never refreshes it. **Fix the split, never the pin**: pin only places carrying no training row, leave contested ones unpinned, and assert the new side is a superset of the old — `write_pin` TRUNCATES [ENFORCED: `finished.write_pin:452` opens `"w"`]. ⚠ The guards catch CONTRADICTION and OMISSION, **not correction** — an in-place edit of a standing registration moves a batch's side with nothing red.
- **★ A ROW MUST LAND IN THE STORE ITS MODE ROUTES TO** — refused at write, excluded at the training read, stored rows untouched [ENFORCED: `finished.py:229,274` — `routed_to` CALLS `hunt.kind_of` rather than copying it, which is the single-spelling discipline working].
- **★ A BLIND SHEET INFORMS EXACTLY ONE BOUNDARY**, chosen by its draw's quality conditioning; blind sheets are eval-only forever. Anchored sheets measure AGREEMENT with the incumbent, and a rate off any prefilled sheet is a CEILING. Standing instruments: blind_minibrot (≥4; its ≥3 rate is the GATED intake's base rate) · blind_modes (≥2/≥3 freely; **≥4 has zero blind positives — NEVER read it** [ENFORCED: all 150 `blind_modes` rows sit in `data/strange_render/eval_split.jsonl`; `test_eval_pins.py`]). ⚠ **smooth ≥4 order on blind_minibrot is ≈ chance for both judges** — eyeball gallery seats before building any instrument. Nothing covers smooth ≥3 or a phoenix:classic base rate — build one WHEN a decision needs it.

## Judge method
- **★ THE WINNER RULE:** candidate only if (a) no overall pre-declared metric significantly worse (95% paired bootstrap) AND (b) the motivating slice significantly better, none worse; declare slices before numbers. **Declare the motivating slice on the WHOLE strange population, never the 3-or-4 subset** — the subset version is a strictly weaker copy of one of its own non-inferiority guards. **A scale-only failure with order intact is a CAPACITY/RECIPE signal before a data signal** — verify the realized recipe before explaining numbers.
- **★ NON-INFERIORITY READS THE BAND.** A per-seed conjunction is a multiplicity trap — any future one PRE-STATES its false-alarm size at registration; cross-seed comparisons score the BAND, never the staged pick. **The model-selection objective is a CONTROLLED VARIABLE** — freeze selection to the baseline-comparable population; amendment before the re-run.
- **★ CORN scale is train-prior-calibrated** — score on AUC, never probability agreement. **TWO RESTATEMENT MODES when a cut must survive a head flip:** VOLUME-MATCHED (same fraction of a fixed reference pool) · HUMAN-DERIVED CROSSOVER (isotonic P(≥boundary)=0.5 on a labeled sheet; the volume change can BE the finding). Every adoption splits rows-vs-scale by refitting the retired artifact over the grown stores first.
- **Test construction:** a reproducibility test re-runs the writer the artifact came from; NEVER construct a test's expected value with the transform under test — a planted red proves the guard bites; a pre-declared bar must OUT-RESOLVE its instrument; a teacher's self-agreement is a ceiling, never a bar. The declared-recipe law (→ fractal-operating) is guarded here, two-ended as claimed [ENFORCED: `render_train.py:259,818`; `render_cv.py:577,632`; `render_acceptance.py:997`].
- A head's render cache must be COMPLETE against its stored rows before it trains [ENFORCED: `renders.plan:331`; `test_renders.py:235,246,286`, slow lane]. ⚠ **`artifacts/renders` does not exist on this machine**, so that build is a real cost standing in front of any training run. The location head is REGIME-ROBUST: **one score SCALE across regimes, not one NUMBER** — never read a cross-regime delta ≤0.3 as a model change (→ fractal-discovery §Regime law).
- **★ THE RENDER JUDGE IS A GATE, NOT A TOP-END RANKER.** Inside `P(≥4) ∈ [0.60, 0.95)` it barely orders Matt's 3-vs-4 verdict, no ≥4 crossover is identifiable in any stratum, a cut there mostly discards Matt's own 4s, and hard optimization of the score there is optimizing noise. Every in-band row came back ≥3, so the ≥3 crossover sits BELOW 0.60, unmeasured. **The ceiling is narrower than that sounds:** unbanded on a grouped holdout the head orders human 3-vs-4 at `AUC(≥4)` 0.650 — 3-vs-4 is NOT irreducible from the picture. What resists is ordering INSIDE the head's own uncertainty band, where conditioning strips most of the variance an AUC reads. **A band-restricted null is weak evidence; the unbanded read on a larger holdout is the better instrument and is what the next bar is declared on.** One resolvable calibration: at matched score a composite is materially likelier to be a 4 than a thin-colour candidate, so **relaxing a bar for a thin cell compounds the error.**
- **★ THE `P(≥4)` COLUMN IS A WELL-CALIBRATED ≥3 SCREEN WEARING A ≥4 NAME.** Its calibration gap is an order of magnitude worse than `P(≥3)`'s; a threshold sweep inside a selected population holds tier-4 precision FLAT across four decades while ≥3 purity climbs to 1.000, and `AUC(≥4)` inside the seats is ≈0.5. **No threshold on this column buys tier-4 precision; every threshold buys ≥3 purity.** ⚠ **A map's prior human label history splits by store — helps smooth, HURTS strange, both CI-excluding; the pooled cross-store reading of it is INVALID and must never be quoted.** Matt ruled the colormap route out regardless; a colour DESCRIPTOR off the finished picture stays open. ⚠ Label-geometry and candidate-geometry columns are indistinguishable on both boundaries and the rows that move between them carry no signal: **the seating regime is not the wrong one to select in; the problem is not where the head reads but what it reads.**
- **★ THE RENDER JUDGE IS NOT REGIME-ROBUST.** Across one doubling of geometry `P(≥4)` is UNBIASED and IMPRECISE, re-levelling adds to the spread, and nearly half of mid-band rows change a 0.10-wide band. **Fit and read on the LABEL-GEOMETRY column, never the candidate one.** A prereg's POPULATION is load-bearing.
- **★ ⚠ THE INCUMBENT'S OWN AUCs ARE TRAIN-SIDE INFLATED** — far higher over train-side rows than over the few eval-only ones, so every AUC measured against it is against an inflated line and is not carryable. ⚠ **No eval instrument exists to grade a retrain with**: the whole ckpt-90 intake is train-side and both stores hold only a few hundred eval rows. **This does NOT block a retrain (Matt, ckpt 92)** — arms graded on identical rows carry the inflation in common, so a PAIRED comparison stands where a LEVEL claim does not. An eval-eligible draw is required before any absolute claim about how good a head is, and not before a retrain that only ranks arms.
- The shipped **RANK KEY** (adopted by eye, default in `curate seat`) is SHARED weights over five columns; per-kind weights are settled against and expected tier as one column loses to freely weighted cutpoints. Form and constants → `preserve\selection_design.md`.
- **Division of labor:** the location head STEERS within-family, NEVER ranks cross-family, and picks FRAMING within one location (→ fractal-discovery) · **ONE render judge (`render`) scores FINISHED renders of both kinds** · the palette head picks palettes within a location, never quality (split keys on LOCATION — settled) · steer/rank/select stay split. **smooth/strange are KINDS**; `smooth_render`/`strange_render` name two LABEL STORES, not a model, and a shared nominal scale does NOT license cross-kind ranking — pools disjoint, floors per kind.

## Sittings — the correction loop IS the labeling method

A stated RULE answers a unit BEFORE it renders; rule verdicts DERIVED never stored; **never pool readouts across rule ids**. Per-sitting correction rate is the head's report card and a CEILING; on modes a head has never seen, agreement is NOISE.
- **★ A sheet is ALWAYS a fresh render at `LABEL_RESOLUTION`**, the geometry both corpora were collected at [ENFORCED: `sheets.LABEL_RESOLUTION:137`, now the single spelling — `shrinkage.py` imports it rather than restating it]; score every sheet picture at label geometry too and carry BOTH readings (`selected_on` = the reading the row was SELECTED on). - **★ ⚠ AUTOLEVEL IS INVISIBLE ON THE ROW** and fires on a large minority of a page, so a sheet built straight off the plan serves a different picture under the same identity. **Measure a pool sheet at label geometry BEFORE building it.**
- **★ ONE POPULATION SPANNING BOTH KINDS IS TWO SHEETS** — `finished.check` routes by `hunt.kind_of` [ENFORCED: `finished.py:274`; `hunt.kind_of:847`]; a single-kind roster is one sheet. ⚠ "Candidate caches give zero hits" is POPULATION-DEPENDENT, not a standing fact. ⚠ `finished_source` writes `facts`, `columns` and a caption UNCONDITIONALLY, so "no editorializing" is not a flag — rewrite `sheet.jsonl` with them emptied. ⚠ `--port` walks upward and prints the port it got — read the banner.
- **★ A SHEET SHOWS ONE RESULT PER LOCATION (Matt).** Consequence: **label-harvest legs want BREADTH at low k; seat legs want DEPTH at high k** — re-split that whenever the objective moves between seats and labels.
- **★ WHEN THE OBJECTIVE IS HARVESTING q3/q4 IN SPARSE MODES, LABEL THE BEST ONLY (Matt)** — a best-of draw already samples good and bad, and a flat control stratum spends Matt's eyes on shapes he has seen dozens of times. The two-strata blind design is for when there is training to trust; proposing it here is a Claude REFLEX to stop.

## Label noise — what it forbids
Disagreement is adjacent-category only: a real ordinal scale with a fuzzy boundary, not a learnability ceiling. **Forbids reading small AUC differences on the ≥3 boundary.** Pre-register bars before computing; verify the instrument's inputs actually change.
