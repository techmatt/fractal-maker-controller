# fractal-discovery — stage 1: sourcing, maneuvers, the hunt

Changes when: discovery/sourcing work. Frame: "is this NEIGHBORHOOD good for a wallpaper?" — locations are palette-free; stage 1 serves type × morphology demand only.

**The order book:** each (fractal × descent method) is a partition with a `target_measure` weight; the deficit scheduler allocates across them. **A new generation type is a NEW partition with its own price — register it in `assign_split` before its batch is built** (fractal-corpus) — minibrot-descent-on-multibrot ≠ native-multibrot band search.

## The machinery
- **Deficit scheduler** (`--scheduler`; OFF = byte-identical): order book projected to per-partition marginals, per-type normalized; deficit denominated in DISTINCT LOOKS (cos<0.974, tallies seeded from the library at launch); pop = largest price-weighted deficit + a 10% exploration floor; cross-partition p_good comparison structurally impossible; ranker absent. Mechanics → `docs/design/discovery_pipeline.md`. Campaign-2: direction right, convergence weak (julia ~22% vs 77% target).
- **Steered frontier** — best-first; Rust `--expand` does rungs, GPU scores batches. **Steer-cheap/admit-canonical** [n=465; no cheap score ever enters a record]. Priority (within partition) = cheap E[ord] + Gumbel + depth bonus − coord-dup − morph-novelty. Harvest: cheap p_good ≥ τ_h → ONE canonical render → CORN decode at per-partition `t_good` → reframe → near-dup → ledger. `sat_frac` ~0.74 (watch, don't tune).
- **Freshness prior** — SHIPPED for breadth (production default), **BANNED in dives** (a precanon cloud containing the dive source = 100% sterilization [measured]). Seam: `build_run_clouds()` (run-only) feeds `draw_roots`; `build_clouds()` (prior⊕run) feeds precanon/near-dup/steering. **Dive mode:** single-track descents off a completed ledger, scheduler-ordered, prior OFF; dives mint count faster than variety (~80% distinct vs ~95%), beat breadth on quality, and **family, not depth, is the quality lever** [human n=298]. Shape: breadth seeds lineages → dives mine → scheduler allocates → ranker sorts.
- **★★★ THE PRIORITY CONTEST STARVES FRESH ROOTS — the biggest measured inefficiency.** Julia probe: 34 of 534 pool c's never touched — they LOST the contest; 68% of budget went on ~2.4 min/look deep re-descent while ~0.11 min/look fresh roots sat available. **A bigger pool does not fix it — the problem is ranking. The floor has never bound and that is NOT evidence it's unnecessary — 44 batches is not a mature frontier; **`quota_bound` is THE statistic to watch on the long run.** `avail-but-unused` 40% = the dedup key working.
